# Current official data layer

`official-updates.json` is the system and business update track. `disaster-loan-announcements.json` is the separate, local disaster announcement track. `coverage.json` records the global coverage conclusion and points to the per-source review log.

This layer is not a complete 115年度手冊, and the disaster announcement track is not an eligibility-determination tool. All records are source guides; users must return to the official source and lending institution.
