# Task Search Semantics

本文件記錄 114.0.0-beta.2.6.1 任務型搜尋的來源語料依據。盤點範圍限於既有 359 頁 PDF 文字層、507 筆搜尋索引、23 項貸款、87 筆函釋及 28 份書表；用途是把使用者語言映射到來源中實際存在的正式詞彙，不產生答案或改寫規定。

計數以 `data/114/pages.json` 的 PDF 原始文字層為準。「頁數」是至少出現一次該詞的不同 PDF 頁數；同頁重複出現只計一頁。

## 申請資格

- 使用者語言／可見 query：`申請資格`
- 最終 concept：`task-eligibility`
- 納入詞：`申請資格條件`（2次／2頁）、`申貸資格`（102次／55頁）、`貸款對象`（60次／41頁）、`本貸款之對象`（21次／21頁）、`救助對象`（4次／2頁）
- 合併後來源證據：97頁
- 來源例子：手冊頁94「農機貸款」的「本貸款之對象」；手冊頁100「輔導農糧業經營貸款」的「本貸款之對象」；手冊頁270「農業天然災害低利貸款」章的「救助對象」
- 排除：`借款人`、`申請人`、單獨的`資格`與`對象`。這些詞出現範圍過廣，不能單獨代表申貸資格規定。

- 最終 concept：`task-loan-purpose`
- 納入詞：`貸款用途`（243次／127頁）、`資金用途`（30次／30頁）、`所需資金`（36次／22頁）
- 合併後來源證據：142頁
- 來源例子：手冊頁26「辦理政策性農業專案貸款辦法」的貸款用途附表；手冊頁147「農民經營及產銷班貸款」；手冊頁251「農業保險貸款」
- 排除：單獨的`用途`與`資金`。兩者會命中大量非貸款用途語境。

## 可以貸多少

- 使用者語言：`可以貸多少`
- 可見 query：`貸款額度`
- 最終 concept：`task-loan-amount`
- 納入詞：`貸款額度`（377次／71頁）、`最高貸款額度`（266次／46頁）、`最高額度`（1次／1頁）
- 合併後來源證據：71頁
- 來源例子：手冊頁16「辦理政策性農業專案貸款辦法」額度附表；手冊頁95「農機貸款」；手冊頁211「青壯年農民從農貸款」
- 排除：單獨的`額度`、`金額`與貨幣數字。它們無法可靠區分貸款額度、申請金額及其他金額。

## 期限與寬緩期

- 使用者語言：`期限與寬緩期`
- 可見 query：`貸款期限 寬緩期`
- 最終 concepts：`task-loan-term`及既有`grace-period`
- 納入詞：`貸款期限`（85次／46頁）、`還款期限`（1次／1頁）、`寬緩期`（133次／31頁）；既有使用者別名`寬限期`在本冊原文為0頁，僅保留為查詢入口
- 合併後來源證據：60頁
- 來源例子：手冊頁95「農機貸款」；手冊頁212「青壯年農民從農貸款」；手冊頁275「農業天然災害低利貸款」
- 排除：單獨的`期限`、`期間`與`年限`。這些詞也常用於補正、申請及行政期間。

## 貸放後管理

- 原使用者語言：`貸後管理`
- 最終標籤／可見 query：`貸放後管理`
- 最終 concept：`task-post-loan-management`
- 納入詞：`貸放後管理`（1次／1頁）、`貸款用途及經營狀況查驗`（6次／6頁）、`用途查驗`（10次／7頁）、`經營狀況查驗`（11次／8頁）
- 合併後來源證據：15頁
- 來源例子：手冊頁13「辦理政策性農業專案貸款辦法」；手冊頁56「農業發展基金貸款作業規範及相關函釋」；手冊頁103「輔導農糧業經營貸款」
- 決定：保留，但改名為來源實際使用的「貸放後管理」。該詞及其具體查驗用語有穩定來源證據。
- 排除：單獨的`管理`、`查核`、`追蹤`、`貸款存續期間`。它們涵蓋內部管理、資格追蹤及非用途查驗內容，噪音過高。

## 擴充方向

新增 Task concept 使用單向 `triggerTerms` → `relatedTerms`。只有完整使用者任務詞能觸發正式用語擴充；搜尋「對象」、「文件」、「期限」等短詞不會反向展開整組 Task terms。既有使用 `terms` 的15組概念仍維持雙向別名行為。
