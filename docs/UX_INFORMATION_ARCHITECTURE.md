# 使用者旅程與資訊架構

本網站定位為「政策性農業貸款查詢工具」。核心承諾是：快速找到貸款規定、函釋與書表，並可回到原始手冊核對。

## 八項設計原則

1. 先回答使用者要往哪裡查，不自動回答申貸問題。
2. 同時保留搜尋、找貸款、依原書瀏覽三條主要路徑。
3. 首頁只呈現四個同層主要入口，次要資料移到次層導覽。
4. Section 依資料語意形成 Hub，不以大量頁碼作為主要導航。
5. 貸款頁聚合原文、相關函釋、相關書表及來源證據。
6. 359 個逐頁頁面完整保留為可追溯證據層。
7. 搜尋結果先顯示所屬脈絡、命中原文及出處，不產生結構化答案。
8. 手機優先保留搜尋、選單與回到頂端，降低浮動工具對正文的遮擋。

## 資訊架構

- 搜尋：知道要查什麼時直接輸入關鍵字。
- 找貸款：知道貸款名稱時依類別進入貸款工作頁。
- 原書完整目錄：需要依原始手冊順序逐項查閱。
- 依需求找資料：用任務與資料類型快速進入相關頁面。

導覽捷徑由 `data/114/navigation-shortcuts.json` 控制。捷徑只送出預設檢索文字，不包含資格、額度、利率、期限或任何自動判斷結果。
