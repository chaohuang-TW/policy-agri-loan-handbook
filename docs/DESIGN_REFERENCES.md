# Editorial design references

研究日：2026-10-02。研究用途是內容組織、閱讀及互動方法，不複製版型、品牌、素材、字型或程式碼；本站未取得任何獎項。

## MONOPOL Online

- [Awwwards官方案例](https://www.awwwards.com/sites/monopol-online)：Nominee，2019-09-25，不是Winner或Site of the Day。
- 已看：官方案例頁及畫面；[現行首頁](https://www.monopol-magazin.de/)DOM。Cookie／隱私遮罩限制現行首頁的完整視覺觀察；保存隱私選擇被環境審核拒絕，未重試。
- 借鑑：標題、簡介與metadata不同層級；主題合集和單筆閱讀入口並存。
- 不採：巨大品牌字標與廣告式入口。本案需讓搜尋立即可用，不新增來源不存在的分類或資料解釋。

## Nordiska Museet

- [Webby官方Cultural Institutions結果](https://winners.webbyawards.com/winners/websites-and-mobile-sites/general-desktop-mobile-sites/cultural-institutions)：2025 Webby Winner，不是People’s Voice。第29屆結果於[2025-04-22公布](https://www.webbyawards.com/press/press-releases/29th-annual-webby-awards-announce-2025-winners/)。
- 已看：[現行首頁](https://www.nordiskamuseet.se/en/)與[Visit options](https://www.nordiskamuseet.se/en/visit-us/visit-options/)內容／DOM；cookie modal限制部分截圖，非完整視覺或無障礙稽核。
- 借鑑：實用入口先於背景敘事；完整說明與快速操作分層。本案只重排既有任務與入口，不增貸款比較或建議。
- 不採：全屏影片、移動歡迎字帶與沉浸式捲動。

## Rijksmuseum

- [FWA官方案例](https://thefwa.com/cases/rijksmuseum)：FWA of the Day，2013-05-05。
- 已看：官方得獎頁及當年畫面；[現行館藏頁](https://www.rijksmuseum.nl/en/collection)，實際開啟篩選抽屜並截圖。現行網站是後續改版，不冒稱與2013版本相同。
- 借鑑：主搜尋清楚、進階條件有收合層級；同一資料集具有探索、搜尋、詳細來源的多個入口。
- 不採：巨幅館藏背景滿屏與文字壓圖；本案不引入圖片或外部runtime。

## 判準與可及性

[Webby官方評審準則](https://www.webbyawards.com/judging-criteria/)重視內容、結構／導覽、視覺、功能與整體體驗。視覺完成度不等同特效数量或WCAG认证。

- [WCAG 2.2 contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：一般文字4.5:1，大字3:1。
- [Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：320 CSS px重排，必要二維資料可例外。
- [Focus not obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum)：自製sticky元件不能完全遮蔽焦點。
- [Target size minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：AA为24px或符合間距等例外。本案主要按鈕採44px，是專案較友善標準，不冒稱AA一律要求44px。
